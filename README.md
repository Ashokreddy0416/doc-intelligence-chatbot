# Document Intelligence Chatbot

A production-grade chatbot that ingests large, messy PDFs (text, tables, images)
and answers questions with cited sources. Built as a deep, step-by-step learning
project, evolving from RAG → hybrid retrieval + reranking → GraphRAG.

## Branches
- `main`    
- `develop`

## Stack
Gemini · Docling · Supabase (Postgres + pgvector) · Neo4j Aura · Upstash Redis ·
LangChain + LangGraph · LightRAG · FastAPI · Streamlit · Docker · GCP Cloud Run
